## 2. Core Advantages of the ALU Language
ALU is a physics-first, proof-carrying systems language. It provides a unified, zero-dependency blueprint that scales from bare-metal microcontrollers to advanced hardware arrays.

*   **Linear Logic Memory Model:** Replaces garbage collection with compile-time tracking of single-use, consume-once capabilities.
*   **Hardware-Enforced CHERI Capability Safety:** Native 128-bit pointer support for bounding and permissions checking to stop spatial and temporal memory exploits at the architectural level.
*   **Formal Verification Engine:** Integrated Hoare-logic pre/post-conditions (`@requires`, `@ensures`) embed mathematical proofs directly into function definitions.
*   **Embedded Black-Magic Primitives:** First-class compiler support for extreme optimizations, such as the `0x5f3759df` fast inverse square root hack and direct CPU trap execution.
*   **Complete System Sovereignty:** Compiles deterministic bare-metal binaries capable of bootstrapping custom kernels, such as Alugandr OS.
