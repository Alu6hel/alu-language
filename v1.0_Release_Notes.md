# ALU Language v1.0 - The Dawn of Mathematical Systems Programming

We are proud to announce the **v1.0 Release of the ALU Language**.

## What is ALU?
ALU is a systems-level programming language engineered with mathematical precision. By enforcing Hoare-logic preconditions and postconditions at compile-time, ALU mathematically proves that a program's memory state is safe before a single byte of machine code is ever generated.

## Features in v1.0
- **The Transpiler Engine**: ALU now dynamically parses ASTs and transpiles directly into C, leveraging local GCC/Clang installations for maximum native performance.
- **The Mathematical Prover**: The `alu_cli` compiler now features a built-in boolean algebra evaluator (`verifier.rs`) that statically analyzes all `prove { }` blocks and halts compilation on invalid memory bounds.
- **ALUPKG (Package Manager)**: Use `alu init` and `alu install` to instantly pull dependencies from the ALU Central Registry.
- **ALU Standard Library**: The official `std/memory`, `std/thread`, and `std/os/windows/wdk` libraries are included out of the box.
- **VS Code Extension**: Premium syntax highlighting and Language Server (LSP) diagnostics via the official `vscode-alu` extension.

*If the math doesn't prove, it doesn't compile.*
